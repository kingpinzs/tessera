# Phase 01 — W10M Start screen with every live tile, the app list, the Settings hub and the onboarding checklist

## Goal
The shell APK installs over adb, becomes the default Home, and shows a Windows 10 Mobile (final release) Start screen on a
360-epx canvas scaled to the display width. Start shows a code-defined W10M default layout of real installed apps. Its tiles are
live: every mapped notifying app's tile is driven by its notifications, plus Photos, Calendar, Music (now playing) and Weather.
Press feedback on Start tiles follows the Q6 setting (default: none). Tapping a tile launches the real app with W10M's measured Start exit animation. Swiping left opens
the W10M app list (search, A-Z with an accent "New" caption under newly installed apps, jump grid), which launches any installed app. On Start and every other
screen the shell owns, the shell hides Samsung's bars and draws the W10M status bar and a Back / Windows nav bar. A W10M Settings hub with a Start +
theme page and an onboarding/health checklist exist. Every visual/motion value is tagged per RV9; values R3 could not measure are listed under Approximations.

## Scope
**In:**
- Toolchain: Android SDK, platform 36, emulator, an AOSP (non-Google, P5) system image AVD at 1080x2340 @ 450 dpi with `hw.ramSize=8192` and `disk.dataPartition.size=16G` (see Decisions); Gradle project; one APK; compileSdk/targetSdk 36
- Branding module (A10): Selawik (OFL), Fluent UI System Icons (MIT), product/assistant names as swappable resources
- Design tokens: px/epx from the display's portrait width (RV10); Density(pxPerEpx, fontScale = 1) at every owned window root; type ramp; accent palette; tile size = f(columns, canvas, gutter, edge) (RV6)
- Motion primitives written in-house (RV5) from R3: Start exit / return (scale + fade + row stagger), tile flip / peek / image crossfade on unsynchronised per-tile timers (R3 A8: flip tiles 4.96 ± 0.22 s, image-crossfade tiles 4.4 ± 0.4 s), page transitions; press feedback per interview Q6
- Permanent tile model in small-tile units + its persistent layout store (moved here from phase 02 on 2026-09-16, because slot assignments must persist)
- Code-defined W10M default layout with assignable app slots: role-backed slots (Phone, Messaging, Browser) follow Android's role holder; category slots (Mail, Music, Maps, Store, Photos, People, Camera) start unassigned unless Android resolves a single or preferred default for that category; tapping an unassigned tile opens a W10M-style app picker filtered to apps that handle the category; Settings > Start can reassign any slot
- Live tile engine (content contract, per-tile queue, staggered random scheduling) + the public Live Tile API over that contract (R5) + real unread-count sources where exposed (R5) + feeds: NotificationListenerService, Photos (MediaStore), Calendar (CalendarProvider), Music (MediaSession), Weather
- Start: grid, scroll, background image through transparent tiles, parallax (R3 A5/A6; approximation X15 until checked on 15063)
- Bottom tile row (post-FINAL change 2026-09-17, see INDEX Change Log): one fixed row of small tiles directly above the drawn nav bar that does not scroll with Start; default Phone, Messaging, Camera
- System bars on Start and this phase's other shell screens (app list, Settings hub, Weather app; the bar rule in Decisions): immersive control that hides Samsung's status and nav bars (swipe reveals them transiently); a drawn W10M status bar fed by the system clock, battery, signal and Wi-Fi state; a drawn nav bar with Back and Windows keys (the Search key is ADDed by phase 03, wired to Cortana)
- App launch: Start exit animation (R3 A11) + solid-colour splash style requested via ActivityOptions; Start return animation on resume
- App list: swipe-left pivot, search, A-Z with the accent "New" caption on newly installed apps (R3 A13 / C2), letter jump grid; live package add/remove
- W10M-style Weather app (current conditions, hourly, 10-day) opened from the Weather tile; location permission + region units; Open-Meteo attribution line (CC BY 4.0)
- Settings hub + Start/theme page (accent, background image, transparency, show more tiles, light/dark, press effect style, show work and private apps)
- Onboarding/health checklist (P4 design, H33) rows for phase 1: HOME role, notification access, media/photos, calendar, location (weather), Usage access (Back on Start), listener liveness, Samsung badge provider readable, legacy badge broadcasts seen
- HOME intent filter and role request flow

**Out (explicitly):**
- Pin / unpin / move / resize / folders: phase 02 (layout persistence itself is here; there is no export/import anywhere, phase 02 Q1)
- Cortana and the Cortana tile: phase 03
- Action center, volume panel, privileged helper, and any helper rows or pages: phase 04 (R3F-02: no pre-built rows)
- Keyboard (05), dialer + SMS (06), glance (07), LLM (08)
- Recents / app switcher (CANNOT, M3); the system return animation and splash rendering (CANNOT, N-09)
- Anything for Jeremy's post-plan "own updates" (no hooks, no future-proofing)

## Edge cases
- Assigned app uninstalled or disabled (slot → unassigned); role holder changes (e.g. default SMS app switched); Android default for a category changes after auto-assignment vs after explicit assignment; no app handles a category at all (picker empty state)
- Notifications: none ever; no usable content; grouped (summary excluded); updated in place; dismissed; redacted/sensitive; ongoing (media, downloads); channel with badges disabled
