## PQ2 — visual voicemail, observe only (phase 06)

- Carrier config: VVM type `vvm_type_cvvm`, carrier VVM app `com.tmobile.vvm.application`, destination 122, port 1808,
  SSL off; `carrier_ims_gba_required_bool` reads true in one config source.
- The system voicemail provider has **no rows**: this phone's voicemail is not in Android's voicemail provider.
- The shell uid holds READ_VOICEMAIL and ADD_VOICEMAIL.
- So phase 06 cannot read voicemail from the system provider on this phone; reading it would need the carrier sign-in
  that PQ2 was scoped not to try (Jeremy 2026-09-28 "A"): the separate sign-in probe before phase 06's voicemail task.
