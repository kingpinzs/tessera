# Phase 06 — W10M Phone and Messaging

## Goal
W10M (final release) Phone and Messaging live inside the shell APK and hold the default dialer (InCallService) and default SMS roles.
Place and receive calls with the W10M in-call UI and call history; read contacts from the Contacts provider; send and receive SMS
(and MMS per interview) in threads. Their notifications feed phase 01's tiles, and Cortana's call and text commands land in them (RV4).

## Scope
**In:** dialer role + InCallService; the W10M Phone page (History / Speed dial / Dial pad icon tabs, app bar with Voicemail and Phone book buttons); incoming-call UI (Slide up, Answer, Text reply, Remind me, Ignore) and in-call UI (Hold, Add call, Merge calls, Bluetooth, Mute, Speaker, Dial pad, call waiting); call history; speed dial; SMS role + receive/send + conversation list + compose + threads; MMS (pictures, group texts, and W10M's attach menu: photo or video, camera, location as a text link, contact, voice note, ringtone); visual voicemail list (P4 design, gated on the R4 probe, PQ2); notifications; role request + restore flow; the drawn W10M status and nav bars on every Phone and Messaging screen (phase 01's bar rule, review R3D-04); settings pages + checklist rows (dialer role, SMS role, phone/SMS/contacts permissions, location for Your location, microphone for Voice note).
**Out (explicitly):** a W10M People app (not in the feature list; Phone book opens phase 01's People slot app); a Contacts or Voicemail tab (W10M had none, R7 §1.1.1); video calls (W10M's Video button was a Skype upgrade with no Android counterpart, R7 §1.6.1); message sync and "Sign in" (no cloud, A11); RCS (a third-party SMS app can't use it); GPL code (R2 licence traps).

## Edge cases
- Emergency numbers must always work; the role being revoked mid-call
- Incoming call while the action center, Cortana or glance is showing; call waiting; Bluetooth headset; DND; blocked numbers
- Call waiting while a call is already on hold; a third incoming call during two calls; Merge refused by the carrier or the network (no "Merge calls" cell); the held party hanging up; a Bluetooth headset connecting mid-call (the Bluetooth cell becomes available)
- Text reply while SMS sending fails (airplane mode, no service): the call is still rejected, and the message shows as failed in its thread; Remind me with phase 03's exact-alarm permission revoked (phase 03's inexact fallback and notice)
- Phone book with phase 01's People slot unassigned or its app uninstalled: phase 01's app picker opens; no voicemail number on the SIM: the "No voicemail number" dialog
- Dial pad row rule at unusual heights (`wm size` with a short display, split-screen or a pop-up window): rows never shrink below the measured 50-epx pitch; below that, the digit rows scroll under the typed-number area (agent pick, H4)
- Your location with location off, the permission denied, or no fix within 30 s: a notice, and nothing is inserted; no network request in any case (the link is text, and the shell never fetches a map)
- Attachment larger than the carrier's MMS size limit (`CarrierConfigManager` `maxMessageSize`): photos are recompressed to fit, and a voice note or ringtone that can't fit is refused with a notice
- Incoming call while the keyguard is locked: the in-call UI shows over the secure lock screen, answer works without unlocking, hang-up returns to the keyguard
- MMS with mobile data off / Wi-Fi only (MMS needs the cellular data path and the T-Mobile APN): send fails with a clear notice and retries when data returns
- SMS_DELIVER arriving while the shell process is dead: the receiver stores the message and the thread shows it on next open
- SIM + eSIM (the S25 Ultra has both): choosing the line ("Call using:" caption on the Phone page, "Send on:" selector in Messaging, R7 §1.1.7 / §2.3.1); one line disabled mid-session (the caption and selector fall back to the single-line forms)
- Multipart SMS; unicode; delivery failure; airplane mode
- Switching the default SMS app away (e.g. back to Fossify Messages) and back; RCS still on (precondition failure path)
- Voicemail: VVM stops working after a successful probe (carrier change, auth failure): the list shows a W10M-style error and the Voicemail button still dials voicemail (a failed probe is not this edge: it re-asks Jeremy, PQ2); the helper's VVM verbs invoked by another app (another uid: refused, logged); voicemail deleted on the carrier side; very long or silent voicemail; transcription model missing
- Liveness (N-01)
