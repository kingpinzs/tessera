### N-04 · MAJOR · Q11's derived consequences stop at Screen zoom; Font size, the density mechanism, the AVD spec and the QA rows are missing
- Claim: (a) Samsung "Font size" (`Configuration.fontScale`) is a separate setting from Screen zoom (density). Compose `sp` text obeys fontScale unless the shell pins it, so an implementer following Q11 literally still gets a non-950 layout at Jeremy's Font size. Derived ruling to add: neither Screen zoom nor Font size resizes the shell; the shell provides `Density(density = pxPerEpx, fontScale = 1f)` at every window root it owns — activity, each overlay window (phases 4, 7), the IME window (phase 5), and every `Dialog`/`Popup`, because each is a separate window that does not inherit the override. (b) "screen width px" should be defined as the shell window's bounds width (`WindowMetrics`), which under edge-to-edge (targetSdk 36) equals display width in portrait and gives integer factors: 1080/360 = 3, 1440/360 = 4. (c) System-drawn parts are separate windows (status/nav bars, permission dialogs, `Settings.Panel`, Samsung Keyboard until phase 5, app splash screens), so nothing breaks — but they follow Screen zoom / Font size while the shell does not; the QA precondition is "default Screen zoom, default Font size" (B1 part 1 was answered "doesn't matter", which is true for the shell only). (d) A2's "match … density" is now irrelevant to the shell; state the AVD as the factory FHD+ 1080x2340 @ 450 dpi (what the phone shows daily) so bar heights compare. (e) Phase 1 emulator rows that prove the rule under Rule 4: `adb shell wm density 420` and `560` → shell unchanged, bars change; `wm size 1080x2340` vs `1440x3120` → identical epx layout; `settings put system font_scale 1.3` → shell unchanged; the activity must survive `density|fontScale|screenSize|smallestScreenSize` config changes without losing state (unverified on One UI; QA on phone).
- Evidence: PLAN.md:102-104 (Q11 names Screen zoom only); PLAN.md:31 "The emulator AVD should match its resolution and density."; fable.md:15 "Reported density is 450 dpi at FHD+ and 560 dpi at QHD+".
- No owner question: agent default is "Font size ignored too", consistent with Q11; Jeremy can overrule (W10M had its own text-scaling setting, not in the feature list).
