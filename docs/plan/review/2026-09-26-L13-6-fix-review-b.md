  3. The row then `tail`s the previous run's `$QA/L13_6/<m>/summary.txt`. If that run was 30/30, the row PASSes, and the setup error appears only in a `note`.
- The evidence here is unaffected: each dir was renamed after its run, and its headers match.
- **Fix:**
  - `rm -rf "$ROW_DIR/$m"` before the probe;
  - assert the setup's and the probe's exit codes;
  - assert that the summary's `apk=` equals `installed_apk_id`.
