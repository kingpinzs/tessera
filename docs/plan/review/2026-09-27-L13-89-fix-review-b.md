## Notes (non-blocking)

**N1. The L13-8 controls are chained, and "gone" is a negative check.** `scripts/l13_8_row.sh:57-67`, and `where()` at :13-21.
- **Failure scenario:** a future build regresses (2). Then (3) FAILs as a cascade and (4) PASSes on Start. Separately, a failed dump in (4) writes "(dump failed)", which reads as "gone" and PASSes.
- **Fix:**
  - Start (3) and (4) fresh, or assert each start state before its Back.
  - Make "gone" positive: `start_page` present.
- **INDEX wording:** the ledger says the first driver's cases "depended on each other". The current driver's (3) and (4) still do; say so.

**N2. The L13-9 driver does not record the order of the Back and B.** `l13_9_row.sh:50-53`.
- **Failure scenario:** a loaded host reorders the two `input` processes at 0 ms, and the row FAILs a correct build.
- **Fix:**
  - Log when the Back arrives (for example, a ring line in the editor's BackHandler) and classify pre-Back trials apart.
  - State that only the 12 trials at 0–5 ms discriminate: the old build lost none of its 18 trials at 10–20 ms.

**N3. The drawn Back at Music's task root.**
- **Before:** the drawn Back from the collection with nothing open called `finish()`, so `onDestroy` ran `MusicPlayer.release()` (the controller only; the session lives on).
- **Now:** it reaches the dispatcher's fallback, `Activity.onBackPressed`. Since Android 12, that moves the task of a root MAIN/LAUNCHER activity to the back instead of finishing it. MusicActivity declares MAIN/LAUNCHER and has its own taskAffinity.
- **Contrast with the Clock:** ClockActivity has an always-on callback that ends in `finish()` (`ClockActivity.kt:208-210`). "The Clock's way" is therefore the routing, not the root behaviour.
- **Why it is only a note:** this now matches the system Back, so it is in scope. But neither the commit nor the ledger says so, and row case (4) cannot tell finishing from moving to the back. Not observed on the device.

**N4. Some Back paths are covered by the mechanism only, with nothing on the device.**
- **L13-9:** the Sound and Snooze time flyouts and the name field. They share the BackHandler and the OverlayLayer the row exercises.
- **L13-8:** the hold menu, the name box, an open playlist, the detail page, and Now Playing's header back.
- `MusicCollectionPage.kt:178-184` is the removed drawn chain verbatim, so in those states the drawn Back is unchanged, apart from the grid now closing first.
