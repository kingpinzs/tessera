## What the doc is
Phase 18 is Windows 10 Mobile's File Explorer ("Files") as an app inside the shell APK: it browses the phone's shared
storage and removable volumes by path under All-files access (`MANAGE_EXTERNAL_STORAGE`), sorts, searches, selects, copies
and moves through a foreground service, renames, deletes into a shell-owned Recycle Bin, shares through a `FileProvider`,
opens / extracts / creates zips, shows Recent, and opens a file in the shell's own app when it has one. Jeremy's interview
answers are in the doc's Decisions (2026-09-23) and are binding: **Q1 A** All-files access; **Q2 C** the full set plus zip
plus Recent; **Q3 C** a shell-owned Recycle Bin for every file type, emptied only by the user; **Q4 A** the shell's own
app opens its types, Android's chooser the rest. Rounds 1 and 2 ran over phases 11–20 on 2026-09-23 (triage ids `T18-…`,
cross-phase `C-<n>`). The doc has not been touched since 2026-09-23 (last commit 86df1a99); its frontmatter status line
