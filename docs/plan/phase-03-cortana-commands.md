# Phase 03 — Cortana persona with offline voice commands

## Goal
Cortana (names from the branding module) opens from its tile, from the assist gesture as the default assistant, and from the side key
where One UI allows it. The persona shows the final-release ring states (idle / thinking / speaking) and the waveform listening
state. Fully offline: microphone → open-vocabulary speech-to-text (one permanent engine) → command matcher → a real Android intent
action → spoken reply (one permanent TTS engine) plus on-screen text. Speech the commands don't match goes to a permanent
"not understood" handler that phase 08 extends. Requests can also be typed into Cortana's text box, as on W10M. Cortana itself makes no network request (the Weather part and the one-time model download are separate).

## Scope
**In:** persona UI + motion (R3); VoiceInteractionService / assistant role; Cortana app-list entry (pinnable via phase 02); Cortana tile (ADD of a Cortana slot to phase 01's default layout + its face); the Search key ADDed to phase 01's drawn Start bar, wired to Cortana; typed requests through Cortana's text box (W10M's Cortana had one, fidelity A4); speech engine, TTS engine and their models; command matcher; intent actions for the ruled command list; confirmation flow (read-back and ask for texts and calls; confirmation card for calendar events and reminders); Cortana's ≡ pane (Home / Reminders / Settings) and its page transitions (R7); Cortana's own reminders (store, exact-time notifications, Reminders page); Notes slot + picker; contacts lookup; not-understood handler; Settings page + checklist rows (assistant role, microphone, contacts, calendar read and write, send SMS, phone calls, exact alarms, background location, call log, SMS read, model presence, service liveness, speech process; review R3T-m13); the speech engines' own `app.tileshell:speech` process; the locked-phone gate in the action layer; the Cortana session's drawn system bars.
**Out (explicitly):** settings-toggle commands (Wi-Fi / Bluetooth / data / airplane): they arrive with the privileged helper in phase 04; free-form answers (08); W10M dialer / SMS UI (06); any "open Settings panel" placeholder for toggles (Rule 16).

## Edge cases
- Silence; background noise; speech interrupted mid-utterance; very long utterance
- Microphone permission denied or revoked; assistant role taken by another app (the Search key opens Cortana's page with the role notice)
- Speech/TTS model missing or corrupt; `espeak-ng-data` checksum mismatch after extraction (re-extracted); the speech process killed or low-memory killed (Start, tiles, listener, IME and dialer unaffected; Cortana says it is reloading and rebinds)
- The Cortana tile unpinned in phase 02 (the once-only ADD does not bring it back after restart, reboot or update)
- Command names an app that isn't installed, or two apps with similar names
- Contact with several numbers or no number; two contacts with the same name; no default SMS app
- Reminder due while the phone is rebooting or in Doze; the shell force-stopped or updated before a reminder is due (re-registered at process start / package replace); a system that revokes `USE_EXACT_ALARM` (checklist row goes red, reminders fall back to inexact with a notice); reminder time in the past
- Confirmation: confirm / cancel / "add more" / "try again" / silence at a text read-back; confirm / cancel / "yes" / "no" / silence at a reminder or calendar card ("add more" is not offered there); a second command spoken while a confirmation is pending; the same flows through the text box
- Slot app (Music / Maps / Camera / Notes) unassigned when its command is spoken
- Weather asked with no weather data ever fetched
- Music playing (audio focus / ducking); incoming call while listening; screen turns off mid-command
- Liveness (N-01): assistant service after reboot, 24 h idle, Device care optimise, service disabled
- Network fully off at all times (proves offline)

- Locked phone (PQ3): side key or assist on the lock screen; each allowed command runs; each gated command shows "Unlock to continue" and completes after unlock; unlock cancelled leaves nothing done; lockdown mode; "Lock screen options" Off (nothing opens over the keyguard); "play <song>" while locked with a Music slot app that has no media session or media browser service ("Unlock to continue"); an alarm voice activity refused over the keyguard (Jeremy re-asked, PQ3)
- Places: typed address not found; several matches (a W10M-style pick list); Nominatim unreachable or rate-limited; a place deleted while a reminder uses it (the reminder card shows the place is gone)
- Place reminders: location services off; background location denied or downgraded to "only while using"; no saved home; GPS drift at the radius edge (fires once, not repeatedly); arriving while the phone is rebooting; the shell updated or force-stopped while a place reminder waits (alerts re-registered, Decisions); a spoken place with no saved place (OWNER question R3D-02 route)
- Person reminders: contact with several numbers (any matches); a number not in contacts; a missed or rejected call (doesn't count as talking); a call still in progress (counts only once it ends); a group text including the contact; a call or text in a direction the R3T-B6 ruling does not count; `READ_CALL_LOG` or `READ_SMS` not allow-listed (checklist rows red, person reminders cannot fire)
