# Phase 07 — W10M glance screen

## Goal
After the screen turns off, a W10M (final release) glance screen shows the time, date and notification icons/counts from phase 01's
listener, with the W10M glance settings (final release page) and proximity/pocket handling ruled in the interview, and never weakens the real secure lock
screen underneath: when a secure lock is set, it never shows over an unlocked phone (with no lock set, see Decisions).

## Scope
**In:** the shell's own glance surface kept on at minimum brightness (a `showWhenLocked` + `turnScreenOn` activity, see Decisions), started only once the keyguard is locked when a secure lock is set; clock, date, notification summary; the 15063 Glance settings page (show toggle, "Show Glance screen for" durations, always show when charging, background picture, night mode); proximity handling; the screen-hold, turn-off and re-trigger rules (turn-off through phase 04's accessibility service); burn-in mitigation; Settings page + checklist rows (reusing phase 04's overlay / "Appear on top" row, Rule 16).
**Out (explicitly):** drawing on Samsung's AOD (not possible without root); replacing lock-screen security (CANNOT); locking the phone with `DevicePolicyManager.lockNow()`.

- 2026-09-16: Glance never shows over an unlocked phone (agent): when a secure lock is set (`KeyguardManager.isDeviceSecure()`), glance starts only once the keyguard is actually locked (`KeyguardManager.isKeyguardLocked()` true), never on the screen-off event alone. One UI's "Auto lock when screen turns off" can delay the lock (up to 30 minutes), and on AOSP a screen turned back on inside that delay cancels the pending lock (`KeyguardViewMediator` `doKeyguardLaterLocked` / `cancelDoKeyguardLaterLocked`), so starting glance at screen-off would leave an unlocked phone behind it and a touch would land on Start or the last app. The screen stays off until the lock engages, so glance appears up to the lock delay late (H11). How the shell learns that the lock engaged while the screen is off is verified at build start and recorded here (UNVERIFIED): `KeyguardManager.addKeyguardLockedStateListener` (needs `SUBSCRIBE_TO_KEYGUARD_LOCKED_STATE`) if that permission can be held by the shell, otherwise a re-check of `isKeyguardLocked()` scheduled from the screen-off time and bounded by the longest delay One UI offers. The shell never locks the phone with `DevicePolicyManager.lockNow()`, which demands strong authentication at the next unlock and would disable fingerprint unlock (P2). With no secure lock set, glance starts on the screen-off event. E6 and P4 prove it (review R2D-01, agent)

## Edge cases
- Charging vs not, and plugging or unplugging while glance shows; incoming call; alarm firing; notifications arriving in bursts
- Pocket / face-down; bright sunlight vs dark room
- Samsung AOD turned on later (conflict); DND
- Switching settings while glance is showing; a night-mode range that crosses midnight
- Power key pressed while glance is showing: the screen really sleeps, glance does not re-trigger in a loop
- Glance ending by its duration, by proximity or by the power key: no glance until the user next turns the display on (pocket mode: a later uncover starts one new glance)
- Screen timeout with One UI's auto-lock delay: nothing shows until the lock engages; a wake inside the delay shows the unlocked phone with no glance
- Power-key sleep with "Lock instantly with side key" off: glance waits for the delayed lock
- Touches on glance do nothing except wake to the keyguard (W10M glance was non-interactive); with lock type None there is no keyguard, so a touch ends glance (Decisions, H12)
- Android lockdown mode; no lock set at all (glance starts on screen-off); extend-unlock active
- Glance finishes on unlock (no glance activity left behind the keyguard or over Start)
- Background activity start restrictions after long idle
- Always-on above the 2 %-per-hour ceiling (Jeremy re-asked)
- Liveness (N-01): reboot, Device care, service disabled (phase 04's accessibility service disabled: glance cannot turn the screen off, so the checklist row goes red and glance does not start)
